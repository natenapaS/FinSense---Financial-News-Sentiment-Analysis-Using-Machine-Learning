# FinSense: Financial News Sentiment Analysis Using Machine Learning

An AI system that analyzes English financial news text and classifies it as **Positive / Negative / Neutral**,
helping investors screen news more quickly.

## Project Structure

```
├── FinSense.ipynb              Main notebook: Problem → Data → EDA → Preprocessing → Training → Evaluation
├── finsense_utils.py           clean_text, stop words, prediction with confidence (shared with the app)
├── app.py                      Streamlit web demo
├── data/all-data.csv           Financial PhraseBank (4,846 sentences)
├── models/finsense_model.joblib  Best model (generated by the notebook)
└── requirements.txt
```

## Usage

```bash
pip install -r requirements.txt

# 1) Run the notebook (open in Jupyter or execute the whole file) — generates models/finsense_model.joblib
jupyter notebook FinSense.ipynb
# or
jupyter nbconvert --to notebook --execute --inplace FinSense.ipynb

# 2) Launch the web demo
streamlit run app.py
```

> The FinBERT comparison downloads a ~440 MB model on first run. To skip it, set `RUN_FINBERT = False` in the first cell of the notebook.

## Method

- **Preprocessing:** lowercase, remove URLs, `n't → not`, numbers → `num`, remove punctuation; keep direction words (not, up, down, more, less)
- **Features:** TF-IDF (unigram/bigram) inside a `Pipeline`
- **Data split (stratified):** Train 70% (3,386) / Validation 15% (726) / Test 15% (726)
- **Hyperparameter tuning:** `GridSearchCV` on Train (5-fold stratified, scoring = macro-F1) comparing Naive Bayes, Logistic Regression, Linear SVM, and Random Forest
- **Model selection:** choose the model type by macro-F1 on the Validation set, then retrain on Train+Validation
- **Evaluation:** evaluated once on the Test set — learning curve / validation curve, classification report, confusion matrix, word weights, error analysis, and comparison with FinBERT
- **Long news (web demo):** the model is trained on single sentences, so long articles are split into sentences (`split_sentences`), each sentence is predicted, and the overall result is the average of the class probabilities

## Results

| Model | Validation Macro-F1 | Test Accuracy | Test Macro-F1 |
|---|---|---|---|
| **Linear SVM** (selected model) | **0.745** | 0.777 | **0.736** |
| Logistic Regression | 0.739 | 0.773 | 0.736 |
| Multinomial NB | 0.713 | 0.730 | 0.672 |
| Random Forest | 0.697 | 0.741 | 0.671 |
| FinBERT (ProsusAI, pretrained)* | – | 0.872 | 0.866 |

\* FinBERT was previously fine-tuned on Financial PhraseBank, so its scores may be overestimated.
